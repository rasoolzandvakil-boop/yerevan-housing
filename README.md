# Yerevan Housing Research

A working dossier on the Yerevan (Armenia) residential market: price and rent dynamics, short-term-rental economics, a district-by-district map, the macroeconomic backdrop, and an annotated directory of data sources.

**Site:** https://rasoolzandvakil-boop.github.io/yerevan-housing/

- `index.html` — overview and key numbers
- `macro.html` — macro backdrop and projections (IMF, World Bank, EBRD, ADB)
- `market.html` — prices, the tax-refund policy engine, all 12 districts
- `rents.html` — rents, yields, Airbnb economics
- `sources.html` — data & intelligence directory with a monitoring calendar
- `Yerevan-Housing-Market-Aug2026.pdf/.docx` — full 14-page report
- `Yerevan-Housing-Market-Slides.pdf/.pptx` — 15-slide deck

Compiled August–September 2026 from official Armenian data (Cadastre Committee, Central Bank of Armenia, ArmStat), IMF/World Bank/EBRD/ADB assessments, Grant Thornton Armenia, and local analysts. Research, not investment advice.
